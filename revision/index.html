How to use these in a 30-minute pass

  1. Minutes 0–5 — skim the headings only. Read every coloured box title in order. This rebuilds the map of the unit before any detail goes in.
  2. Minutes 5–20 — read the tables and flow chains. Do not read them as prose. For each comparison table, cover one column with your hand and recall it, then check.
  3. Minutes 20–26 — read only the TRAP, MEMORY and FACT boxes. These carry the facts that are most often lost between reading and the exam hall.
  4. Minutes 26–30 — do the blank-fill drill at the end of the unit with the answers covered. Anything you miss, go straight back to that box and read it once more. That single loop is what fixes the forgetting.

Printing

  • Open a unit and press Print / Save PDF in the blue bar (or Ctrl + P).
  • Set Paper size A4, Margins: None, and tick Background graphics — otherwise the colour coding is lost and the sheets become much harder to scan.
  • Print double-sided — 46 pages in all becomes about 23 physical sheets for the whole subject.
  • Do not change Scale. Leave it at Default/100%. If the print preview shows a white band down the bottom of every page, your Margins are not set to None.

A note on the symbols

  • ★ after a heading means this point is asked repeatedly; ★★★ means treat it as compulsory.
  • A □ line in the drill is a fill-in-the-blank; the underlined amber text is the answer.
  • Colour coding is only for navigation — it lets your eye find the same kind of box again quickly on a second pass.
